# creative_writing Skill

## Core Guidance

- Match the tone and register requested in the prompt (formal, casual, technical, narrative).
- Open with a hook — avoid starting with generic filler sentences.
- Use concrete, specific details over vague generalities.
- Vary sentence length to create rhythm; avoid monotonous uniform-length sentences.
- Prefer active voice over passive voice.
- End with a satisfying close that echoes or resolves the opening.
