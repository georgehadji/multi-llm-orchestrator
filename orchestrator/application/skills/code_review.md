# code_review Skill

## Core Guidance

- Structure feedback as: severity (CRITICAL/HIGH/MEDIUM/LOW), location, issue, suggested fix.
- Always check: security vulnerabilities, null-safety, exception handling, and type correctness.
- Point out missing tests or untested edge cases.
- Acknowledge good patterns in the code before listing issues.
- Be specific — quote the exact lines being referenced.
- Distinguish between bugs (must fix) and style suggestions (optional).
