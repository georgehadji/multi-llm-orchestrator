# summarization Skill

## Core Guidance

- Lead with the single most important takeaway.
- Compress factual content, not just length — cut redundancy, not substance.
- Preserve all key numbers, dates, names, and decisions from the source.
- Use the same terminology as the source to avoid introducing confusion.
- For long documents: use a brief TL;DR paragraph followed by bullet-point details.
- Never editorialize unless explicitly asked — report, don't interpret.
