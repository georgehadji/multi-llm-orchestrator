# complex_reasoning Skill

## Core Guidance

- Break the problem into clearly labelled sub-problems before solving.
- Show intermediate steps — never jump directly to the conclusion.
- State assumptions explicitly at the start.
- When uncertain, enumerate multiple candidate answers with pros/cons before committing.
- Use concrete examples to validate abstract reasoning.
- End with a concise summary of the conclusion and its confidence level.
