# Category 9: Collaboration & Team Features

> **Focus:** Multi-user work, team-level templates, and community marketplace.
> **Phases:** 3 | **Est. Days:** 7-10 | **Weight:** 5% of total roadmap

---

## Overview

This category enables **team-scale usage** of the orchestrator — shareable project templates, a marketplace where creators can sell templates, and portable skill files for external AI coding agents.

| # | Phase | Source | Description | Days | Dependencies |
|---|-------|--------|-------------|------|-------------|
| 1 | W5 | Bolt.new | **Team Templates** — shareable project configurations capturing architecture, entities, auth, modules, integrations, and environment templates | 2-3 | V7 |
| 2 | X5 | Create.xyz | **Template Marketplace** — sell/buy templates for credits, review & rating system, seller dashboard, approval workflow | 3-5 | V7 |
| 3 | B7 | Base44 | **Skills for External AI Agents** — portable SKILL.md files teaching Claude, Cursor, and Copilot how to work with orchestrator-generated projects | 2-3 | 8, B1 |

---

## Capability Progression

```
Team Templates (shareable project configs)
    │
    ├── Template Marketplace (buy/sell with credits, reviews)
    │
    └── External Agent Skills (Claude, Cursor, Copilot)
```

## Key Innovations

- **Team templates** capture the full project configuration — not just code, but architecture, entities, and modules
- **Template marketplace** enables a creator economy where builders can monetize their templates
- **External agent skills** extend the orchestrator's reach to AI tools the user already uses
